## 🚀 featured builds

### 🛒 [SellerOS](https://github.com/Havish06/SellerOS) — *the one that took 3 days and 300 messages*

> Full-stack multi-platform inventory & order management system — built entirely on vibes and Claude

This started as a VIT lab assignment and became a **production-grade system** with:

- 🗄️ **18-table MySQL schema** — roles, inventory, orders, customers, cart, wishlist, OTP tokens
- ⚡ **5 auto-firing triggers** — stock deduction, negative stock guard, status logs, cart clear
- 🔐 **Full RBAC** — 5 roles (Admin → Delivery), DB-level permission flags, 7+ protected routes
- 💳 **3 transaction endpoints** — atomic orders, bulk orders, stock transfers with rollback
- 🛍️ **Customer shopping site** — separate auth system, cart, wishlist, OTP forgot-password
- 👔 **Staff portal** — one login for all roles, sidebar adapts automatically
- 📊 **EXPLAIN analysis** — 6 named queries with index optimization

**`MySQL`** **`Node.js`** **`Express`** **`Vanilla JS`** **`HTML/CSS`**
