### 🛒 [SellerOS](https://github.com/Havish06/SellerOS) — Multi-role inventory & order management system

A full-stack backend-heavy system built for a college project that turned into something closer to production-grade. This is the project I'm proudest of because it's mostly about correct database design under real constraints.

- 18-table MySQL schema covering roles, inventory, orders, customers, cart, wishlist, and OTP tokens
- 5 database triggers handling stock deduction, negative-stock prevention, and status logging at the DB layer instead of the app layer, so data stays consistent regardless of which client hits it
- Role-based access control across 5 roles, enforced with DB-level permission flags and 7+ protected routes
- 3 transaction endpoints (single order, bulk order, stock transfer) written with atomicity and rollback in mind
- Query optimization pass using `EXPLAIN` on 6 core queries, with indexing to back it up
- Separate customer-facing shopping site (cart, wishlist, OTP-based password reset) and an internal staff portal with one login that adapts by role

`MySQL` `Node.js` `Express` `JavaScript` `HTML/CSS`
