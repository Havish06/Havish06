## 🚀 Featured Projects

### 🛒 [SellerOS](https://github.com/Havish06/SellerOS)
> Multi-platform seller inventory & order management system — full stack, from schema to UI

A complete business management platform built for VIT BCSE302L Lab Task 1.

**What's inside:**
- 📦 **12-table MySQL schema** — branches, platforms, RBAC roles, inventory, orders, deliveries
- ⚡ **5 MySQL triggers** — stock deduction, negative stock prevention, status logging, cart clearing, pre-order stock check
- 🔐 **Role-Based Access Control** — Admin / Manager / Seller / Viewer / Delivery with DB-level permission flags
- 💳 **Transaction management** — atomic order placement, bulk orders, stock transfers with full rollback
- 🛍️ **Customer shopping site** — separate auth, cart, wishlist, addresses, OTP password reset
- 👔 **Staff portal** — single login, sidebar adapts per role automatically
- 📊 **EXPLAIN analysis** — 6 named queries for index and query optimization demos

**Stack:** `MySQL 8.0` `Node.js` `Express` `Vanilla HTML/CSS/JS`
